# Modal / Popup Window

This is my Week 2 Project 3 for the Syntecxhub Front-End Development internship.

## What I added
- A button that opens the popup
- Dark overlay behind the popup
- Close button
- Opening and closing animation
- Contact form inside the popup
- Close by clicking outside the popup
- Close with the Esc key
- Message character counter
- Simple form submit message
- Responsive layout for smaller screens

## How to run
Open `index.html` in a browser.
