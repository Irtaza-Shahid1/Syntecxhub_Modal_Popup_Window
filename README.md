# Irtaza Shahid — Portfolio Website

This project was created for the Syntecxhub Front-End Development Week 1 task.

## Task Requirements Covered

- Single-page portfolio
- About section
- Skills section
- Projects section
- Contact section
- Clean and modern colour scheme
- Responsive design for desktop, tablet and mobile
- Hover effects
- Basic transitions
- HTML and CSS only

## How to Run

1. Extract the ZIP file.
2. Open the `Syntecxhub_Portfolio_Website` folder.
3. Double-click `index.html`.
4. The portfolio will open in your web browser.

No installation, terminal command or external package is required.
